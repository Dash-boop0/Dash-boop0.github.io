How these are built

  • Browser tools: plain HTML, CSS and JavaScript, with no frameworks, paid APIs or tracking. Agent systems: FastAPI, PostgreSQL and Next.js, with mock providers and dry-run sending by default.
  • Every metric and score has a written definition and is covered by automated tests with hand-checked examples.
  • Sample datasets are synthetic and labelled as such; no real clients, results or contacts are shown.
  • Browser tools save data in your browser; the agent-system demos use a shared demo database that an admin can reset.
